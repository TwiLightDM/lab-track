# Система учёта оборудования лаборатории

Веб-приложение для централизованного хранения информации о приборах и инвентаре лаборатории, регистрации операций (
перемещение, выдача, ремонт, обслуживание, списание) и разграничения доступа сотрудников.

Система решает проблему разрозненности сведений об оборудовании за счёт единого каталога, быстрого поиска (в т. ч. по
QR-коду), учёта перемещений и выдач, контроля технического состояния и ролевого разграничения доступа.
